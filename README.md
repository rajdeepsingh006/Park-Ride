# 🚗 Park & Ride - Smart Parking & Last-Mile Connectivity Platform

A full-stack MERN application that enables users to book parking near metro stations, reserve last-mile rides (cabs, e-rickshaws), and access contactless check-in/out using QR codes, LPR (License Plate Recognition), and RFID scanning.

## 🔧 Tech Stack

- **Frontend**: React, React Router, Bootstrap
- **Backend**: Node.js, Express.js, MongoDB (Community Edition)
- **Features**:
  - Parking slot reservation
  - Ride booking and cancellation
  - QR code generation for contactless entry
  - Simulated LPR and RFID-based check-in/out
